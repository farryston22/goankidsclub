# Goan Kids Club

Free learning games for Goan children aged 3 to 6: numbers, UK phonics, shapes, thinking, animals,
Konkani and Goan heritage. No ads, no sign-up. Works on iPad, phone and computer.

- `games/` – the Play & Learn games (see `games/README.md`)
- Preview locally: `node serve.js`, then open http://localhost:5180/

Maintained by Claude (see `CLAUDE.md`).
